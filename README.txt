3. Review Privacy Policy and Terms to match actual hosting, analytics, forms and business practices.
4. Replace YOUR-DOMAIN.com in sitemap.xml and robots.txt after choosing the final public domain/Pages URL.
5. The website currently uses Google Fonts, which makes an external browser request.
6. The email link opens the visitor's email app; this package does not include a server-side enquiry form.
7. No phone or WhatsApp number is published, per the current contact preference.
8. This package does not establish domain availability, company registration, trademark clearance or legal compliance.

GITHUB PAGES
- Upload the extracted files (not the ZIP) to the root of your repository.
- Keep index.html, style.css and script.js together in the repository root.
- In repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
- Wait for the deployment to complete before sharing the live site.
