PREMIER TECHNOLOGIES WEBSITE
================================

Files:
- index.html       Main bilingual website
- style.css        Black and gold responsive styling
- script.js        Mobile menu, Urdu/English switch, current year
- privacy.html     Starter privacy policy
- terms.html       Starter terms of use
- sitemap.xml      Search engine sitemap template
- robots.txt       Search engine crawl instructions
- favicon.svg      Browser icon

BEFORE PUBLISHING:
1. Replace YOUR-DOMAIN.com in index.html, sitemap.xml and robots.txt with the real public website URL.
2. Replace YOUR_EMAIL@example.com in index.html with a dedicated contact email you are authorized to publish.
3. Read Privacy Policy and Terms and update them to match the actual services, hosting, forms, analytics and contact methods you use.
4. The current contact link opens the visitor's email app; it does not submit or store a website form.
5. The current site does not include user accounts, payments, analytics or a server-side database.
6. The Google Fonts import in style.css makes a request to Google Fonts. Remove the @import line if you prefer not to load an external font.
7. Test the pages on mobile and desktop after deployment.

GITHUB PAGES:
Upload the files in this folder to the root of a new repository (or a repository you have deliberately chosen for this website), then enable GitHub Pages from the repository's Settings > Pages. Do not overwrite the separate VideoHub Pro repository unless you intentionally want to use it for this brand website.

This is a starter website template, not a claim that a company is registered or that the brand/domain/trademark has been cleared.
